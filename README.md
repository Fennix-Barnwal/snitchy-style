# SNITCHY STYLE

## Run locally

```bash
npm install
npm run dev
```

The current visual direction uses CSS-generated animated graphics instead of clothing photography. The graphics are used in the hero, fit cards, before/after section, process steps, and customisation panel. Add real product photography later by replacing the `AnimatedArt` components in `src/App.jsx`.

The customisation form is currently a prototype: submissions are not sent or stored. The optional photo upload only previews the selected image in the browser.
